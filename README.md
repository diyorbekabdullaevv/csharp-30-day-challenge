# 30 Days of C#

A 30-day personal challenge to strengthen my C# programming fundamentals
through daily learning and coding practice.

## Challenge

- Start: October 5, 2026
- End: November 5, 2026
- Time: 1 hour per day
- Language: C#
- Learning: [W3Schools C# Tutorial](https://www.w3schools.com/cs/)
- Practice: [Exercism C# Track](https://exercism.org/tracks/csharp)

## Goals

- Strengthen C# fundamentals
- Improve problem-solving skills
- Become more confident writing code independently
- Build a stronger programming foundation for Unity and game development
